# QQ喵喵助手

一个让 QQ 聊天变成猫猫语气的 Android 辅助工具，基于**无障碍服务**实现。

## 功能

- 自动将「你」替换为「主人」
- 自动将「我」替换为「本喵」
- 断句加喵（标点后自动加「喵」）
- 消息末尾随机附上猫咪颜文字
- 支持自定义颜文字库
- 处理模式：标点触发 / 实时处理

## 技术栈

- Java
- Android Gradle Plugin 8.4.0
- Material Components（蓝鲸公益 LJGY 玻璃拟态 UI 风格）
- `minSdk 23` / `targetSdk 34`

## 使用方式

1. 安装 APK 后，打开主界面
2. 点击「前往开启无障碍服务」，给 QQ喵喵助手开启无障碍权限
3. 回到 QQ 聊天，在输入框打字，文本会自动被替换成猫猫语气

## 界面

UI 采用「蓝鲸公益」官网的玻璃拟态 + 蓝色系设计语言。
