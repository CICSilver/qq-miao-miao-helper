# ===========================================================
#  颜文字关键词表
# ===========================================================
#
#  格式：  关键词 = 情绪标签
#          关键词 =              ← 右边留空 = 排除短语
#
#  情绪标签要和颜文字库里段落头左半边的标签对得上，对不上的词
#  不会报错，只是永远选不出东西来。
#
#  匹配方式：左到右【最长优先】扫描整句原文（未经关键词替换的原文），
#  命中的片段会被吃掉不再重叠匹配；扫完取【最后一个】命中的作准。
#
#    「别难过，我陪着你」   → 别难过(安慰)      「难过」被「别难过」吃掉了
#    「今天有点不开心」     → 不开心(难过)      同理
#    「刚才难过，现在开心」 → 开心              取最后一个
#
#  排除短语：命中后【弃权】，既不用它的情绪、也不让更短的词接管，
#  直接降级到句尾符号判断。适合「不喜欢」这种否定了但也谈不上
#  相反情绪的说法，以及「加油站」这种把「加油」整个吃掉的干扰词。
#
#  最终候选 = 情绪标签命中的 ∩ 符号标签命中的；空了就按
#  合成表 → 只看情绪 → 只看符号 → 全库 依次降级。
#
#  空行和 # 开头的行会被忽略。
# -----------------------------------------------------------
