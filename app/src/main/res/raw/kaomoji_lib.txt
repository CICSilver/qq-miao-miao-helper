# ===========================================================
#  颜文字库
# ===========================================================
#
#  每张脸挂两组标签，各管一件事：
#
#    情绪标签   这张脸表达什么心情  ← 由句子里的关键词决定
#    符号标签   这张脸适合什么句尾  ← 由句尾标点决定
#
#  最终候选 = 情绪标签命中的 ∩ 符号标签命中的。
#  两组都挂全，句尾语气才不会在降级时被丢掉。
#
# -----------------------------------------------------------
#  格式
# -----------------------------------------------------------
#
#    [情绪标签,... | 符号标签,...]     ← 段落头，以下的脸都挂这组标签
#    (=・ω・=)                         ← 一行一张脸
#    (=^ω^=) | (=^w^=)                ← 竖线后面可选：纯 ASCII 降级版
#
#  段落头一直生效到下一个段落头。同一组情绪可以开多个段落，
#  给不同的脸配不同的符号标签。
#
#  为什么不再用「标签 = 颜文字」？因为颜文字本身就含 '='（猫脸的眼睛
#  就是 =），迟早会切错。现在整个文件不靠 '=' 分割 —— 段落头用方括号、
#  降级版用竖线，这两个字符在全部 160 多张脸里一次都没出现过。
#
# -----------------------------------------------------------
#  符号标签一共这七个
# -----------------------------------------------------------
#
#    句号    句尾是 。—— 它会被吃掉，所以这其实是「陈述句」的意思
#    问号    ？
#    叹号    ！
#    问叹    ？！ / ！？ —— 难以置信
#    省略号  连打的 。。 会被折成 ...
#    波浪    ～         ← 数据已就位，但目前【不触发】
#    爱心    ♡ ♥ ❤      ← 同上
#
#  波浪和爱心是随词库一起带进来的，要不要让它们也当确认键还没定。
#  想开启的话改 MeowCommitter 的 isTerm 即可，这边不用动。
#
#  空行和 # 开头的行会被忽略；文件末尾是 @default 和 @merge。
# -----------------------------------------------------------

# ===========================================================
#  默认情绪
# ===========================================================
#
#  句子里一个情绪关键词都没命中时用哪一组。
#
#  这一层必须有。没有的话会降到「只看符号」，而符号组是
#  【全部】配得上这个句尾的脸 —— 哭的、生气的、害怕的全在里面
#  等概率抽，一句「今天把接口改完了。」抽到张哭脸，看起来
#  就像标签打错了。没有情绪信号本身就是一种信号。
# -----------------------------------------------------------

@default 平静


# ═══════════════════════════════════════════════════════════
#  情绪合成表
# ═══════════════════════════════════════════════════════════
#
#  格式：  @merge 情绪标签 + 符号标签 = 结果情绪标签
#
#  用在「关键词说一种情绪、句尾说另一种，两边交集却是空」的时候。
#  比如「什么意思！」：关键词说困惑，而困惑组的脸只配了句号/问号/
#  省略号，没有一张挂叹号。它真正的语气是难以置信，也就是惊讶
#  —— 这种「两种情绪叠起来等于第三种」推不出来，只能在这里列。
#
#  合成表没命中也不要紧，后面还有：只看情绪 → 只看符号 → 全库，
#  任何句子都拿得到颜文字。
#
#  左边写 * 表示「不管原本什么情绪」。多条命中时写在前面的先赢，
#  所以通配规则要放最后。
# -----------------------------------------------------------

# 困惑撞上叹号 = 难以置信
@merge 困惑 + 叹号 = 惊讶
@merge 困惑 + 问叹 = 惊讶
# 思考被打断成了感叹，多半也是没想通
@merge 思考 + 叹号 = 惊讶
@merge 思考 + 问叹 = 惊讶

# ？！ 本身就是「难以置信」，这层语气盖过句子原本的情绪 ——
# 「好难过？！」重点不在难过而在不敢相信。没有更具体的规则时一律走惊讶组。
@merge * + 问叹 = 惊讶
