# ===========================================================
#  颜文字关键词表
# ===========================================================
#
#  格式：  关键词 = 情绪标签
#          关键词 =              ← 右边留空 = 排除短语
#
#  匹配方式：左到右【最长优先】扫描整句原文（未经关键词替换的原文），
#  命中的片段会被吃掉不再重叠匹配；扫完取【最后一个】命中的作准。
#
#    「别难过，我陪着你」   → 别难过(安慰)      「难过」被「别难过」吃掉了
#    「今天有点不开心」     → 不开心(难过)      同理
#    「刚才难过，现在开心」 → 开心              取最后一个
#
#  排除短语：命中后【弃权】，既不用它的情绪、也不让更短的词接管，
#  直接降级到句尾标点判断。适合「不喜欢」这种否定了但也谈不上相反情绪的。
#
#  最终选中的颜文字 = 关键词标签 ∩ 标点标签；交集为空时关键词优先。
#
#  空行和 # 开头的行会被忽略。
# -----------------------------------------------------------
