# ===========================================================
#  默认颜文字库
# ===========================================================
#
#  格式：  标签1,标签2 = 颜文字
#
#  为什么标签写在左边？因为颜文字本身就含有 '='（猫脸的眼睛
#  就是 =），写在左边的话分隔符会切在脸中间。标签永远不含 '='，
#  所以放左边是安全的。
#
#  一个颜文字可以挂多个标签，标签是自由文本 —— 想加新情绪
#  直接写个新标签即可，不需要改代码。
#
#  末尾自带 ? 或 ! 的颜文字有特殊待遇：句尾标点与它同类时，
#  原标点会被吃掉，由颜文字代劳，避免出现「？ (=･ｪ･=)?」这种双问号。
#
#  文件末尾还有一段 @merge 情绪合成表，见那里的说明。
#
#  空行和 # 开头的行会被忽略。
# -----------------------------------------------------------

# ===========================================================
#  情绪合成表
# ===========================================================
#
#  格式：  @merge 关键词情绪 + 标点情绪 = 结果情绪
#
#  什么时候用得上？关键词说一种情绪、标点说另一种，两个池子却毫无
#  交集的时候。比如「什么意思！」——
#
#      关键词「什么意思」→ 困惑        困惑组的脸都自带问号，配叹号很怪
#      句尾「！」        → 兴奋        兴奋组太欢快，根本不是这个意思
#      交集              → 空
#
#  它真正的语气是【难以置信】，也就是惊讶。这种「两种情绪叠起来等于第三种」
#  没法从标签本身推出来，只能在这里一条条列。
#
#  没有命中的合成规则时，仍然按老规矩降级：关键词组 → 标点组 → 全库，
#  所以这张表漏了什么也不会导致句子拿不到颜文字。
#
#  标点情绪只有这五个：平静（句号被吃掉）、疑问（？）、兴奋（！）、
#  惊讶（？！）、无奈（。。 折成的省略号）。
#
#  多条规则命中时，写在前面的先赢。
# -----------------------------------------------------------

# 困惑撞上叹号 = 难以置信
@merge 困惑 + 兴奋 = 惊讶
@merge 疑问 + 兴奋 = 惊讶
# 疑惑句直接打了 ？！ 时，交集同样是空的，一样归到惊讶
@merge 困惑 + 惊讶 = 惊讶
@merge 疑问 + 惊讶 = 惊讶
